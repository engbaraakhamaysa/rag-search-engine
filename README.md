# RAG Search Engine

A search engine that combines traditional keyword search, semantic search, and Retrieval-Augmented Generation (RAG) to retrieve relevant information and generate answers.

## Features

- **Keyword Search:** Text processing and TF-IDF scoring.
- **Semantic Search:** Embedding-based search and chunked document retrieval.
- **Hybrid Search:** Combines keyword and semantic search.
- **Query Expansion:** Improves search results by expanding user queries.
- **Re-ranking:** Reorders search results by relevance.
- **Search Evaluation:** Evaluates search quality.
- **RAG Generation:** Generates answers using retrieved information.
- **Multimodal Image Search:** Supports searching for images using multimodal techniques.

## Technologies

- Python
- Natural Language Processing (NLP)
- Semantic Search
- Retrieval-Augmented Generation (RAG)
